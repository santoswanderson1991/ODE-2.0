\# ODE Framework



Framework PHP para desenvolvimento de sistemas Delivery sobre WordPress.



\## Requisitos



\- PHP 8.2+

\- WordPress 6.8+

\- Composer 2



\## Arquitetura



\- PSR-4

\- SOLID

\- Repository Pattern

\- Service Layer

\- DTO

\- Validators

\- Providers

\- AJAX First
